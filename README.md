# ✈️ NOBILIUM — Turismo e Mobilidade

Um website corporativo moderno, responsivo e altamente premium para a **NOBILIUM**, uma empresa focada em transformar viagens em experiências únicas com soluções completas em turismo e mobilidade.

## ✨ Visão Geral

Este projeto foi construído como uma *Single Page Application (SPA)* focada na melhor experiência de usuário possível (UX). O design transmite luxo, confiança e exclusividade, contendo animações fluidas baseadas em scroll e interações de alto nível.

## 🚀 Funcionalidades

- **Design Premium**: Interface luxuosa construída com cores baseadas em Azul Marinho, Azul Oceano e Dourado.
- **Scroll Suave**: Navegação transparente por toda a página via `react-scroll`.
- **Animações e Micro-Interações**: Elementos que surgem de forma elegante na tela através da biblioteca `Framer Motion`.
- **Diferenciais e Serviços**: Componentes em formato de *cards* modernos para listar passagens aéreas, passeios, vistos e aluguel de veículos.
- **Galeria Interativa**: Seção visual para demonstração de rotas e destinos com efeitos "glassmorphism".
- **Integração com WhatsApp**: 
  - Botão flutuante dinâmico.
  - Formulário de contato que captura *Nome*, *Serviço Desejado* e *Mensagem* e redireciona automaticamente para o WhatsApp da empresa.
- **Totalmente Responsivo**: Layout otimizado para celulares, tablets e desktops de telas largas (Ultrawide).

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/) 19**
- **[Vite](https://vitejs.dev/)**: Para um ambiente de desenvolvimento rápido e *build* otimizado.
- **[Tailwind CSS v4](https://tailwindcss.com/)**: Estilização baseada em utilitários e sistema `@theme` direto no CSS.
- **[Framer Motion](https://www.framer.com/motion/)**: Para orquestração de transições suaves e efeitos de interatividade.
- **[React Icons](https://react-icons.github.io/react-icons/)**: Biblioteca de ícones vetoriais.
- **[React Scroll](https://www.npmjs.com/package/react-scroll)**: Navegação local nas seções do site.

## 💻 Como rodar o projeto localmente

Siga as instruções abaixo para executar o projeto na sua máquina local.

**1. Clone o repositório ou acesse a pasta do projeto:**
```bash
cd Nobilium
```

**2. Instale as dependências:**
```bash
npm install
```

**3. Inicie o servidor de desenvolvimento:**
```bash
npm run dev
```

O terminal exibirá o endereço local onde o site está rodando, geralmente em `http://localhost:5173/`. Acesse o link através do seu navegador.

## 📦 Build para Produção

Para gerar a versão otimizada do site pronta para deploy:
```bash
npm run build
```
O código compilado será gerado dentro da pasta `dist/`.
